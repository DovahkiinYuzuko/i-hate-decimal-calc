## 1. 代数変換プロセス途中式ツリー & 射影 (`--explain`)

`ihd` は、統一プロベナンスDAG（導出有向非巡回グラフ）に基づき、代数式の簡約、分母の有理化、二重根号外し、因数分解、微積分、ロピタルの定理などの導出ステップを追跡・可視化します。

### 1.1 Unicode 2D 途中式ツリー

```bash
ihd --lang ja --explain "limit((sqrt(1 + x) - 1 - x/2) / x^2, x, 0)"
```

```text
式: limit((sqrt(1 + x) - 1 - x/2) / x^2, x, 0)
├── [Step 1: べき乗の微分公式の適用]
│   べき乗の微分公式: d/dx [x^2] = 2*x
│   x^2  ──>  2*x
│
├── [Step 2: 極限値計算・不定形の代数解消]
│   ロピタルの定理適用: (d/dx [-1 + sqrt(1 + x) + -x/2]) / (d/dx [x^2]) = (-1/2 + 1/(2 * sqrt(1 + x))) / (2 * x)
│   -x^2^-1 - 1/2*x*x^2^-1 + √(1 + x)*x^2^-1  ──>  -1/(4*x) + 1/4*√(1 + x)^-1*x^-1
│
├── [Step 3: べき乗の微分公式の適用]
│   べき乗の微分公式: d/dx [√(1 + x)^-1] = -√(1 + x)^-3/2
│   √(1 + x)^-1  ──>  -√(1 + x)^-3/2
│
├── [Step 4: 極限値計算・不定形の代数解消]
│   ロピタルの定理適用: (d/dx [-1/2 + 1/(2 * sqrt(1 + x))]) / (d/dx [2 * x]) = (-1/4 * sqrt(1 + x)^-3) / (2)
│   -1/(4*x) + 1/4*√(1 + x)^-1*x^-1  ──>  -√(1 + x)^-3/8
│
├── [Step 5: 極限値計算・不定形の代数解消]
│   極限値計算: lim_{x->0} -1 * x^2^-1 + sqrt(1 + x) * x^2^-1 + -1/2 * x * x^2^-1 = -1/8
│   -x^2^-1 - 1/2*x*x^2^-1 + √(1 + x)*x^2^-1  ──>  -1/8
└── [Result]
    = -1/8
```

## 4. REPL リアルタイム引数ガイド & 構文ハイライト

単一レキシカル有限状態機械（FSM）により、対話型シェルでのリアルタイム入力を支援します。

- **引数ガイド & シグネチャヘルパー**: 関数入力中、現在カーソルがある引数を強調表示し、引数名と説明を動的に表示します。
- **レインボー括弧**: `()` および `[]` のネスト深度（4色循環）に応じたハイライト。括弧の不整合はエラー警告色（赤背景）で表示します。
- **カスタム変数ハイライト**: 定義済み変数のみを淡いシアンで識別着色します。
- **テーマ設定**: `theme dark` / `theme light` で切り替え可能（`~/.ihd/config.json` に永続化）。
- **セッション保存・復元**: `save <path.ihd>` で現在の定義済み変数をスクリプトとして保存し、`load <path.ihd>` で復元します。
- **類似数式検索**: `similar(<expr>)` で入力履歴から抽象構文木（AST）構造が近い過去の計算式をスコアリング検索します。

## 5. Typst 数式エクスポート (`--typst` / `--format typst`)

Markdown や Typst ドキュメントへ貼り付け可能な Typst 記法（`$ ... $`）で出力します。

```bash
ihd --typst "1/2 + sqrt(2)/2"
# 出力: $1 / 2 + (sqrt(2)) / 2$

ihd --format typst "[[1, 2], [3, 4]]"
# 出力: $mat(1, 2; 3, 4)$
```

---

## 6. LaTeX 数式エクスポート (`--latex` / `--format latex`)

LaTeX 論文や TeX ドキュメントへ貼り付け可能な記法（`$$ ... $$`）で出力します。

```bash
ihd --latex "1/2 + sqrt(2)"
# 出力: $$ \frac{1}{2} + \sqrt{2} $$

ihd --format latex "[[1, 2], [3, 4]]"
# 出力: $$ \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix} $$
```

## 7. コレクション・リスト操作 & 第一級ラムダ式

Python スタイルのスライス構文（`[start:end:step]`）、有理数刻み数列生成 `range`、第一級無名関数 `lambda`、および高階関数 `map`, `filter` をサポートしています。

```bash
ihd "map(lambda(x, x^2), range(1, 5))"
# 出力: [1, 4, 9, 16]

ihd "[10, 20, 30, 40, 50][1:4]"
# 出力: [20, 30, 40]
```

## 8. 厳密有理数ベクトル空間による物理単位計算 & 次元解析

有理数体 $\mathbb{Q}$ 上の 7 次元ベクトル空間（SI基本7単位）に基づき、物理単位の加減乗除、組立単位・接頭辞の展開、次元整合性検証、および単位換算（`convert_unit`）を実行します。

```bash
# 単位の乗除算と約分
ihd "10 [m/s] * 5 [s]"
# 出力: 50 [m]

# 接頭辞と組立単位を含む減算（スケール正規化）
ihd "1 [km] - 200 [m]"
# 出力: 4/5 [km]

# 厳密分数による単位換算
ihd "convert_unit((1/4) [h], min)"
# 出力: 15 [min]

# 独立証明書付き単位換算自己検証
ihd --verify "convert_unit(100 [km/h], m/s)"
# 出力:
# 250/9 [m/s]
# [VERIFIED: convert_unit(100[km * h^-1], m * s^-1) == 250/9 [m/s]]
```

## 9. 意味論的差分判定 (`diff`)

2つの数式またはスクリプトを比較し、展開や因数分解による代数的同値性（`EQUIVALENT`）や相違（`CHANGED`）を判定します。

```bash
ihd diff "x^2 - 1" "(x - 1)*(x + 1)"
# 出力:
# Semantic Diff: x^2 - 1 <-> (x - 1)*(x + 1)
#   ~ [EQUIVALENT] L1: x^2 - 1 <=> (x - 1)*(x + 1)
```

## 10. 高等数学・専門分野のワンショット計算例

```bash
# 初等超越方程式の閉形式求解（Lambert W関数）
ihd "solve(x*exp(x) == 1, x)"
# 出力: [lambert_w(1)]

# ガウス積分の初等閉形式化（誤差関数 erf）
ihd "integrate(exp(-x^2), x)"
# 出力: 1/2*√(π)*erf(x)

# 初等幾何学の完全自動証明（呉の方法）
ihd "geo_prove([midpoint(M, A, B), midpoint(N, A, C)], parallel(M, N, B, C))"
# 出力: true

# ガロア群算定と代数的不可解性証明書（Abel-Ruffini）
ihd --verify "is_solvable_by_radicals(x^5 - 4*x + 2)"
# 出力:
# false
# [VERIFIED: AbelRuffini(2 + x^5 + -4 * x)]

# 素有限体上の楕円曲線位数決定（Schoof法）: ec_p_order([A, B], p)
ihd "ec_p_order([1, 1], 5)"
# 出力: 9

# 整数行列標準形と有限生成アーベル群構造同定（HNF / SNF）
ihd "abelian_group_structure([[2, 4], [4, 2]])"
# 出力: Z_2 + Z_6
```
