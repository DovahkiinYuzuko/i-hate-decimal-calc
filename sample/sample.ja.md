## 1. 2D Braille 点字プロッタと SVG / Typst ベクター出力 (`plot` / `plot_svg`)

Unicode 2×4 点字文字（50×16 文字、100×64 サブピクセル解像度）で端末に関数グラフを描画します。零点・極値・可除特異点・漸近線を記号解析で抽出し、同じプロット結果から SVG（800×500）および Typst（`cetz-plot`）ベクターコードも生成できます。

### 1.1 基本曲線プロットと明示的レンジ指定

第 3 引数 `[y_min, y_max]` を省略すると上下にパディングを足した有理数レンジへ自動スケーリングされます。軸の端点を厳密値で固定したい場合は第 3 引数を明示します。

```bash
ihd --lang ja "plot(sin(x), [-pi, pi], [-1, 1])"
```

### 1.3 SVG / Typst ベクター出力とファイル保存

`plot` の結果に `--format svg` や `--typst` を組み合わせると、そのまま資料や論文に埋め込めるベクターソースを出力します。`--out <path>` または `plot_svg` の末尾文字列引数で UTF-8（BOM なし）ファイルへ直接保存できます。

なお、`--format svg` はプロット式に対してのみ有効であり、通常の数式へ指定すると終了コード `1` のエラーを返します。また、`--out` は単一ファイルへ複数行結果や対話出力を混在させないため、パイプ入力・スクリプト実行（`run`）・`--step` と併用すると終了コード `1` のエラーになります。これらをファイルへ保存する場合は標準出力リダイレクト（`>`）を使用します。

```bash
# SVG を直接ファイル保存（--format svg + --out または plot_svg）
ihd --format svg --out sin.svg "plot(sin(x), [-pi, pi])"
ihd "plot_svg(sin(x), [-pi, pi], \"sin.svg\")"

# Typst (@preview/cetz-plot:0.1.4) コードをファイルへ保存
ihd --typst --out sin.typ "plot(sin(x), [-pi, pi])"
```

`--typst` 指定時に生成される Typst コード（中間座標の一部を省略）は以下の通りです。

```typst
#import "@preview/cetz:0.5.2"
#import "@preview/cetz-plot:0.1.4": plot

#cetz.canvas({
  plot.plot(
    size: (10, 6),
    x-min: -3.14159, x-max: 3.14159,
    y-min: -1.18806, y-max: 1.18806,
    x-label: [$x$],
    y-label: [$y$],
    {
      plot.add(((-3.14159, 0), (-2.60977, -0.507106), ... , (3.14159, 0)), label: [$sin(x)$], style: (stroke: (paint: blue, thickness: 1.5pt)))
    }
  )
})
```

## 2. 3D 空間プロッタと CAS 厳密特徴点解析 (`plot3d` / `plot3d_svg`)

連続 2D 隠線処理（HLR）と視点適応 3D 座標軸を備えた Braille ワイヤーフレームで、3D グラフを端末上へ描画します。曲面は `plot3d(expr, x_range, y_range, [opts...])`、パラメトリック空間曲線は `plot3d([x(t), y(t), z(t)], t_range, [opts...])` で指定します。曲面プロットでは勾配とヘッセ行列による厳密な臨界点分類（極小・極大 `●`、鞍点 `◆`、退化臨界点 `◇`）を自動実行します。

```bash
ihd --lang ja "plot3d(x^2 - y^2, [-2, 2], [-2, 2])"
```

## 6. 物理単位・コレクション操作・意味論的差分

### 6.1 厳密有理数ベクトル空間による物理単位計算と次元解析

有理数体 $`\mathbb{Q}`$ 上の 7 次元ベクトル空間（SI 基本 7 単位）に基づき、物理単位の乗除算、接頭辞・組立単位のスケール正規化、次元整合性検証、および単位換算（`convert_unit`）を実行します。

```bash
# 単位の乗除算と約分
ihd "10 [m/s] * 5 [s]"
# 出力: 50 [m]

# 接頭辞と組立単位を含む減算（スケール正規化）
ihd "1 [km] - 200 [m]"
# 出力: 4/5 [km]

# 厳密分数による単位換算
ihd "convert_unit((1/4) [h], min)"
# 出力: 15 [min]

# 独立証明書付き単位換算自己検証
ihd --verify "convert_unit(100 [km/h], m/s)"
# 出力:
# 250/9 [m/s]
# [VERIFIED: convert_unit(100[km * h^-1], m * s^-1) == 250/9 [m/s]]
```

### 6.3 意味論的差分判定 (`diff`)

2 つの数式または `.ihd` スクリプトを比較し、展開や因数分解による代数的同値性（`EQUIVALENT`）と相違（`CHANGED`）を判定します。

```bash

# 出力:
```

## 7. 閉領域の第一級 AST ノード演算 (`padic_expand` / `puiseux` / `interval`)

p 進切断級数、ピュイズー級数、有理閉区間は文字列へ変換せず第一級 AST ノードとして保持されます。そのため、精度や区間幅・依存関係を保ったまま後続の四則演算や微分・比較を直接続けられます。

### 7.1 p 進切断級数 (`padic_expand`)

素数 $`p \ge 2`$ と正の整数精度 `prec` を指定します（合成数 $`p`$ や切断ゼロによる除算はエラーを返します）。

```bash
ihd "padic_expand(1/3, 5, 4)"
# 出力: 2 + 3*5 + 5^2 + 3*5^3 + O(5^4)

ihd "padic_expand(1/3, 5, 4) * 3"
# 出力: 1 + O(5^4)
```

### 7.2 ピュイズー級数 (`puiseux`)

代数曲線 $`F(x, y) = 0`$ の分岐展開を第一級ノードのリストとして返し、そのまま要素の微分や四則演算を行えます。

```bash
ihd "puiseux(y^2 - x, y, x, 3)"
# 出力: [-x^(1/2) + O(x^3), x^(1/2) + O(x^3)]

ihd "diff(puiseux(y^2 - x, y, x, 3)[1], x)"
# 出力: (1/2)*x^(-1/2) + O(x^2)
```

### 7.3 有理閉区間 (`interval`)

依存性問題を保存した区間演算と 3 値順序比較を実行します（`low > high` や 0 を含む区間の負べき乗は定義域エラーとなります）。

```bash
ihd "interval([1, 2]) - interval([1, 2])"
# 出力: [-1, 1] (width: 2)

ihd "interval([1, 2]) < interval([3, 4])"
# 出力: true

ihd "interval([1, 3]) < interval([2, 4])"
# 出力: [1, 3] (width: 2) < [2, 4] (width: 2)
```

## 8. 有理二乗和分解・イデアル所属・代数的実数の証明書

### 8.1 有理 SOS 分解と Lean 4 非負性証明 (`sos_decompose`)

多変数多項式が有理数係数で二乗和（Sum of Squares）として表せるかを判定し、結果に応じて 3 種類のステータス（`certified` / `refuted` / `no_certificate_found`）を返します。`certified` となった式は `--verify` による恒等式逆算および `--lean` による Lean 4 非負性定理コードの生成に対応します。

```bash
# 非負多項式の有理 SOS 分解と自律逆算検証
ihd --verify "sos_decompose(x^4 + 2*x^2*y^2 + y^4 + 1)"
# 出力:
# [certified, [[1, x^2 + y^2], [1, 1]]]
# [VERIFIED: x^4 + 2 * x^2 * y^2 + y^4 + 1 == (x^2 + y^2)^2 + (1)^2]

# 負の値を取る多項式に対する反例証人（refuted）の返却
ihd "sos_decompose(x^2 - y^2)"
# 出力: [refuted, [[x, 0], [y, 1]]]
```

### 8.2 イデアル所属の余因子証明書 (`ideal_member`)
